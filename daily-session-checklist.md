# Daily session checklist

## Before starting
- [ ] Agent has read the memory index
- [ ] Agent named the decisions binding today's task
- [ ] Agent named the failures already recorded in this area

## While working
- [ ] Every failure recorded when it happens, not later
- [ ] Every important claim has a source or a measurement

## Before closing
- [ ] Today's decisions written, with reasons
- [ ] Today's failures written, unsoftened
- [ ] Index updated
- [ ] Handoff written for the next session

## Once a month
- [ ] Audit old decisions, retire the ones whose condition is met
- [ ] Delete stale state notes
